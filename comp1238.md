## Week 1 - History

- One writing system can be used by many languages.
- Cuneiform was an early writing system.

## Week 2 - Bits and Bytes

- A bit is the smallest unit of digital information.
- Eight bits make one byte.


## Week 3 - Structure of a Text File

- Punctuation, whitespace, and line breaks affect how text is structured and displayed.
- Markup languages, such as Markdown and HTML, use tags or symbols to format text. Raw view shows the source, while rendered view shows the formatted result.
- Structured data formats, such as JSON and XML, organize information in a consistent format.
- Special characters sometimes need escaping so they can be interpreted correctly rather than treated as formatting or syntax.


- ## Week 4 - Keyboards, Text Editors, and Searching

- **Keyboards, touch-typing, and keyboard shortcuts:** Learning to type efficiently and use shortcuts to perform tasks faster.
- **Text editors:** Examples include Notepad, vi, [VS Code](https://code.visualstudio.com/download), and [Notepad++](https://notepad-plus-plus.org/).
- **Searching in text:** Wildcards help match patterns when searching, while regular expressions (regex) allow more advanced text searches.

- ## Week 5 - Command Line Basics and Bandit

- **SSH (Secure Shell):** A tool used to connect securely to a remote computer. The Bandit game uses SSH on port `2220`.
- **Bandit game:** An online game from [OverTheWire](https://overthewire.org/wargames/bandit/) that teaches command-line basics and information security.
- **Levels and passwords:** Each level has a username, such as `bandit0` or `bandit1`. The goal is to find the password for the next level.
- **Basic commands:** Use `ssh` to connect to the server and `exit` to end the remote session and return to your local computer.
